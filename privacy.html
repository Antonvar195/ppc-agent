Privacy Policy

Last updated: June 1, 2026

1. About This Application

This application ("pps-agent 2" / "ppc-agent") is an internal marketing automation tool developed for and used exclusively by Apollo Next fitness club network (apollo.online). It is not a public-facing application and is not available to third-party users.

2. What Data We Collect

This application does not collect personal data from end users. The application:

  • Accesses Meta (Facebook) Marketing API to create and manage advertising campaigns on behalf of Apollo Next
  • Reads campaign performance data from the Meta Ads account owned by Apollo Next
  • Uses Dropbox API to access advertising creative files stored in the Apollo Next team folder
  • Operates through a Telegram bot interface accessible only to authorized Apollo Next marketing team members

3. How Data Is Used

All data accessed through this application is used solely to:

  • Create, manage, and optimize paid advertising campaigns on Facebook and Instagram
  • Upload advertising creative materials (images and videos) to Meta's advertising systems
  • Log campaign launch history for internal reporting purposes

4. Data Access and Security

Access to this application is restricted to authorized employees of Apollo Next. API credentials and access tokens are stored securely and are never shared with third parties. The application uses official Meta Marketing API, Dropbox API, and Telegram Bot API.

5. Third-Party Services

This application integrates with the following third-party services:

  • Meta (Facebook) — for advertising campaign management. See Meta's Privacy Policy.
  • Dropbox — for accessing creative files. See Dropbox's Privacy Policy.
  • Telegram — for the bot interface. See Telegram's Privacy Policy.
  • Anthropic (Claude AI) — for processing campaign briefs. See Anthropic's Privacy Policy.

6. Data Retention

Campaign launch history is stored locally in JSON format on the server running this application. No personal data of end users is retained.

7. Government Requests

This application does not collect or store personal data of users. In the event of any legal request for data, we would only be able to provide information about our own advertising campaigns, not personal data of any individuals.
