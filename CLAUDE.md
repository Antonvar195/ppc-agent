## Що це за проект
Мультиагентна система автоматизації запуску рекламних кампаній Meta Ads
для мережі фітнес-клубів Apollo Next. Управління через Telegram.

---

## Перед будь-яким записом у Meta

1. **Створювати через `tools/meta_guard.js`** — не голими `apiPost`. У ньому
   живуть граблі, на які ми вже наступали: `createAdSet` / `createAd` (валідація
   через `validate_only` + PAUSED за замовчуванням), `promotedObjectFrom`
   (кастомна конверсія), `normalizeTargeting` (плейсменти).
2. **`promoted_object` копіювати з живої групи**, не збирати руками —
   `pixel_rule` звіряється посимвольно (subcode 1885014).
3. **Звіряти креативи по `thumbnail_hash` / image hash**, НЕ по `video_id` —
   Meta підміняє id на свої копії (`meta_guard.verifyAd`).
4. **Не звітувати «готово» без виводу перевірки** — `checkPreviews` +
   `campaignSummary`. «Запустив» ≠ «працює».
5. **Перевіряти реальні розміри креативів** (`ffprobe`/`sips`) — назви файлів
   брешуть.

Аудит наявних скриптів: `node tools/meta_guard.js audit` (🔴 зламає запис ·
🟡 перевірити вручну · ⚪️ не критично). Знахідку читати в контексті — grep
бачить токен, але не намір. Свідомий відступ декларувати `// guard:allow-live`.

Повний журнал із симптомами й датами: `docs/LESSONS.md`.
Нові граблі → запобіжник у `meta_guard.js` + рядок у `LESSONS.md`.

## Критичні правила

1. **PAUSED завжди** — всі об'єкти в Meta API створюються зі статусом PAUSED
2. **Публікація тільки після апруву** — явне "ок" або "запускай" від користувача
3. **.env не коммітити** — токени тільки локально, ніколи в GitHub
4. **Читай rules.md** — перед будь-якою роботою з неймінгом або посиланнями
5. **Один агент = одна задача** — не суміщай ролі агентів

## Флоу запуску кампанії

```
ТЗ від користувача
  → naming_agent (JSON з назвами)
  → utm_agent (JSON + UTM)
  → link_checker (перевірка посилань)
       ❌ помилка → стоп
       ✅ OK → далі
  → validator (превью для апруву)
       ← апрув від користувача
  → publisher (створення в API, статус PAUSED)
  → запис в history/launches.json
  → підтвердження користувачу
```
