# ARCHITECTURE.md — переехал

Архитектура системы управления рекламой описана в соседнем проекте:

**`../ppc-analyst/ARCHITECTURE.md`**

Там же живёт весь аналитический контур: уровни аналитики, лестница гипотез,
журнал решений, накопленные выводы.

Этот проект (`ppc-agent`) отвечает только за **запуск и изменение** объектов
в Meta Ads. Аналитика ничего здесь не меняет — она читает и предлагает,
решение исполняется через инструменты этого проекта после апрува.
